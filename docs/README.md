## Что убрано при очистке

Удалены первоначальный ANALYSIS.md с неактуальными путями/предположениями и три файла starter/ (заготовка с пустыми ролями, старая инструкция и отдельные зависимости). Рабочий код не импортировал starter; актуальные правила перенесены/сведены в методологию и README. Исходные версии доступны в истории Git до коммита очистки.

Данные, опубликованные результаты, локальный current.json, .venv, demo-наборы, Docker volume, frontend-предложение и рабочие тесты сохранены. Исторический большой PLAN заменён текущим чеклистом; формулы доступны в methodology.md. Активные логи и кэши не удалялись, чтобы не затронуть работающий процесс.
