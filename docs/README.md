## Что убрано при очистке

Удалены первоначальный ANALYSIS.md с неактуальными путями/предположениями и три файла starter/ (заготовка с пустыми ролями, старая инструкция и отдельные зависимости). Рабочий код не импортировал starter; актуальные правила перенесены/сведены в методологию и README. Исходные версии доступны в истории Git до коммита очистки.

Данные, опубликованные результаты, локальный current.json, .venv, demo-наборы, Docker volume, frontend-контракт и рабочие тесты сохранены. Исторический большой PLAN заменён текущим чеклистом; формулы доступны в methodology.md. Активные логи и кэши не удалялись, чтобы не затронуть работающий процесс. Позднее объединены backend и его документация.

## Структура после подготовки к аудиту

UI перенесён в `frontend/`, аналитика — в `backend/core/`, CLI — в `backend/`. Текущие команды запуска приведены в корневом README. Данные и результаты сохранены локально, исключены из индекса Git и Docker build context; на чистом клоне их нужно предоставить отдельно. История Git по-прежнему содержит ранее закоммиченные данные.
