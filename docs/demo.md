## Как объяснять evidence

Денежные суммы и количества — факты внутри выборки. Роль — результат правил; пороги находятся в manifest и [методологии](methodology.md). Если разрыв между ролями мал, раскрыть «Альтернативная роль и все признаки», назвать альтернативу. Высокий priority не является вероятностью нарушения; peripheral не означает безопасность.

Полный разбор качества объяснений — [аудит evidence](evidence-audit.md).

## Если что-то не работает

При ошибке SHA256 не показывать частичный/смешанный набор. Пересчитать через make run либо открыть заранее проверенный сохранённый run и назвать его сохранённым. Кэш UI обновляется кнопкой в «О данных и ограничениях». Не выдавать сохранённое время за время нового live-run.

Две репетиции с секундомером и проверка машины показа остаются ручной задачей команды; этот документ не подтверждает их проведение.
