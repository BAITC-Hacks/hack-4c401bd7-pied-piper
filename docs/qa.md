# Приёмка результата и UI

Этот протокол выполняется после того, как Lane A передаст опубликованный bundle. Synthetic fixture подтверждает только UI и контракт; он не закрывает пункты ниже для реального набора.

## 1. Воспроизводимый запуск

```bash
.venv/bin/python pipeline.py --data data --out outputs
.venv/bin/python validate.py --data data --out outputs
```

Зафиксировать в протоколе: дату, commit, Python/dependency versions, `run_id`, фактическое `stage_runtimes_seconds.total`, код возврата и stdout validator. Требования: pipeline <300 секунд, `status=complete`, `validation.status=passed`.

## 2. Контроль артефактов

- Есть `current.json` и ровно указанный им `runs/<run_id>/`.
- Есть пять файлов результата и `run.json`; SHA-256 из manifest совпадают с файлами.
- `nodes_roles.csv` содержит 2 248 уникальных `gid`; каждый имеет одну допустимую роль, один кластер, score [0,1] и непустой evidence не длиннее 200 символов.
- `clusters.csv` покрывает все узлы через `cluster_id`; изоляты не потеряны.
- `top_nodes.csv` содержит не менее 20 уникальных `gid`, ранги без пропусков; каждый `gid` согласован с `nodes_roles.csv`.
- В `run.json` присутствуют counts, версии, пороги, normalization scales, веса priority, runtimes, role distribution и warnings.

## 3. Сверка содержания

Для трёх случайных `gid`, одного boundary и одного изолированного seed:

1. Найти `gid` в UI при активных ограничивающих фильтрах: карточка должна открыться независимо от фильтров.
2. Сверить роль, cluster_id, role_score, priority_score и evidence с CSV/parquet.
3. Сверить число и направление прямых рёбер с `edges.parquet`.
4. Проверить, что priority равен сумме четырёх contributions.
5. Для boundary убедиться в предупреждении об усечении; для seed — в предупреждении о неполном входящем контексте.

## 4. UI smoke

```bash
./run-ui.sh --outputs outputs
.venv/bin/python -m pytest -q
```

Вручную проверить: обзор компонентов/кластеров, Top, поиск существующего и неизвестного `gid`, 1–2-hop ego-граф, входящие/исходящие таблицы и скачивание трёх CSV. Убедиться, что UI показывает только опубликованный bundle и понятную ошибку при отсутствии/повреждении `current.json`.
