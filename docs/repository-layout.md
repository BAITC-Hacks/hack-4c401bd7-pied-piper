# Структура репозитория после реорганизации

Дата: 2026-09-23. Команды выполняются из корня репозитория.

## Переносы

| Прежний путь | Текущий путь |
| --- | --- |
| `app.py` | `frontend/app.py` |
| `src/view.py`, `src/graph_ui.py`, `src/graph.html`, `src/presentation.py` | `frontend/` |
| Остальные аналитические модули `src/` | `backend/core/` |
| `pipeline.py`, `validate.py` | `backend/pipeline.py`, `backend/validate.py` |
| `PLAN.md`, `TECHNICAL_LANE_B.md`, `AUDIT_LANE_A.md` | `docs/` |
| Подробное содержимое корневого README | `docs/product-guide.md` |

Backend и frontend остаются Python-пакетами в одном окружении. Общие зависимости,
Dockerfile, Compose и команды Make оставлены в корне. Streamlit по-прежнему читает
bundle напрямую. Формулы аналитики и схемы результатов при переносе не менялись.
Импорты, subprocess-команды валидатора, тесты и пути HTML-шаблона обновлены.
CLI запускается через `python -m backend.pipeline` и `python -m backend.validate`.

## Очистка

Удалён дублирующий `run-ui.sh`; его функцию выполняет `make ui`. Старый каталог
`src/` удалён после переноса. Исторические отчёты сохранены для аудита.
Данные и опубликованные результаты исключены из индекса Git, но сохранены на диске.
`.gitignore` исключает данные, результаты, окружения, кэши, runtime и локальные `.env`.
Ранее закоммиченные данные остаются в истории Git; история не переписывалась.

Docker build context содержит только необходимые исходники и зависимости.
В тестовый образ добавлен `scripts/smoke_backend.py`, необходимый для HTTP-тестов.
Контейнеры используют прежние volumes, сохранённые результаты не удалялись.

## Границы проверки

Это реорганизация проекта, а не заключение о прохождении внешнего аудита.
Параллельные изменения кодировки CSV-экспорта сохранены в рабочей копии и образе;
они не относятся к переносу файлов. Исторические отчёты в других документах
содержат результаты прежних версий.

## Выполненные проверки

- `docker compose config --quiet` — успешно.
- `docker compose build ui tests` — runtime и тестовый образ собраны.
- `docker compose run --rm tests` — 172 passed (180,77 с).
- После включения параллельных CSV-изменений образ пересобран:
  `docker compose run --rm tests python -m pytest tests/test_csv_downloads.py tests/test_backend.py tests/test_backend_http.py -q`
  — 31 passed (69,67 с). Это целевой повтор, а не второй полный прогон.
- Локальный полный прогон сначала дал 169 passed и 3 ошибки старого пути
  monkeypatch. Путь исправлен; повтор всего `tests/test_a_verification.py`
  дал 19 passed. Полный контейнерный прогон выше выполнен с исправлением.
- Независимый validator локально и в Docker — passed: 2 248 узлов,
  3 119 рёбер, 81 seed, 20 строк Top, warnings=[] при проверке результатов.
- UI и API отвечают на health endpoints; Compose использует новые образы.
- Ссылки документации, наличие локальных данных и `git diff --check` проверены.

Pytest сообщает одно предупреждение об устаревании HTTPX-адаптера Starlette;
оно не связано с переносом файлов. Браузерный визуальный QA в этом проходе
не выполнялся; существующие Streamlit AppTest входят в полный набор тестов.
